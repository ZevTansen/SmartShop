# SmartShop

SmartShop is an online store that lives entirely in the browser. We built it for our CSE-3532 mid project with nothing but HTML, Tailwind CSS and JavaScript. Products are pulled live from the [FakeStore API](https://fakestoreapi.com), and the cart, coupons, balance and wishlist all update in real time.

## Run it

Open `index.html` with Live Server in VS Code, or run:

```bash
python -m http.server 8000
```
